EVIDENCE (PROD, 2026-10-01)

Neither head has ever loaded

  • /app/artifacts/v2-gate doesn't exist, and there is no ML_GATE_* env at all — so the gate sits at its code default, pointing nowhere.
  • ML_POTENTIAL_ARTIFACT_DIR=/ml/artifacts/v2-potential — missing the /app prefix; the path doesn't exist. One line, host .env:82, injected into web and cron.
  • No ML_POTENTIAL_EXIT_MODE → the ML2 overlay defaults to shadow, so it computes and never applies.
  • The only meta present anywhere is the pattern one — the head we keep.
